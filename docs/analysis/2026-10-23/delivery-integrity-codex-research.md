Of 148 intervals, 140 were approximately 90 seconds, despite a requested 15-second cadence. That number is a count of retained monitoring events, not a token or dollar estimate. A deterministic notification when a decision is needed, a run completes, or progress is stale would remove this recurring work while preserving the board for detail.
